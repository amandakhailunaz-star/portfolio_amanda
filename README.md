# Portofolio Amanda Nazwa

Website portofolio sederhana untuk menampilkan profil, minat, keterampilan, hobi, proyek, dan kontak.

## Teknologi
- HTML5 semantik
- CSS
- Bootstrap 5.3.3 melalui CDN
- JavaScript sederhana untuk membuka email melalui formulir kontak

## Menjalankan secara lokal
Buka `index.html` di browser. Karena Bootstrap dimuat melalui CDN, perangkat memerlukan koneksi internet untuk memuat gaya Bootstrap.
